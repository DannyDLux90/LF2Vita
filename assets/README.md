# Vita artwork

The local hardware-test workspace contains the following packaged PNG assets:

- `menu_bg.png`
- `check_bg.png`
- `manual_bg.png`
- `portraits.png`
- `stages/00_sp.png` … `stages/08_ft.png`

Some of these test assets are based on/derived from the user's locally supplied Little Fighter 2 artwork. They are therefore not copied into this public source repository. A matching downloadable workspace snapshot contains the exact assets used for each test VPK.

The native source does not require external web downloads at runtime; all artwork used by the VPK is packaged in `app0:`.
