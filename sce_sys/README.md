# sce_sys workspace

The source repository tracks the LiveArea XML layout. The matching hardware-test workspace additionally contains the binary Vita shell artwork and nine 960×544 manual pages:

- `icon0.png`, `pic0.png`
- `livearea/contents/bg.png`, `startup.png`, `cheat.png`
- `manual/001.png` … `manual/009.png`

The manual uses Vita button symbols/direction arrows and LF2-style imagery. Binary artwork derived from locally supplied game art is kept in the downloadable workspace snapshot rather than redistributed in this public Git repository.
